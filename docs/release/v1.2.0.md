# Release v1.2.0

This release introduces new debugging and network testing capabilities to `kubesrv`.

## New Features

### Kubernetes Debug Endpoint

A new endpoint `/debug/k8s` has been added to provide runtime information from the Kubernetes environment. This is useful for debugging and validating the pod's state.

**Endpoint:** `GET /debug/k8s`

**Response:**
```json
{
  "pod_name": "...",
  "namespace": "...",
  "node_name": "...",
  "pod_ip": "...",
  "service_account": "...",
  "hostname": "..."
}
```

### Network Tester Endpoints

Two new endpoints have been added to test network connectivity from within the cluster.

**DNS Lookup:** `GET /dns?host=<hostname>`

This endpoint resolves a hostname and returns the IP address.

**Response:**
```json
{
  "host": "...",
  "resolved_ip": "...",
  "success": true
}
```

**TCP Connectivity Test:** `GET /tcp?host=<host>&port=<port>`

This endpoint tests TCP connectivity to a given host and port and measures the latency.

**Response:**
```json
{
  "host": "...",
  "port": ...,
  "connected": true,
  "latency_ms": ...
}
```

## Other Changes

- Improved security by escaping user-provided input in JSON responses.
- Fixed potential crashes and bugs related to error handling and buffer sizes.
