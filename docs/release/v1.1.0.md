# Release v1.1.0

## Features

### ConfigMap Volume Mount Support
- Read messages from any mounted ConfigMap file via `MESSAGE_FILE` environment variable
- Supports full file paths (e.g., `/usr/share/kubesrv/message.txt`)
- Fallback priority: `MESSAGE_FILE` → `MESSAGE` env → default message
- Default mount path: `/usr/share/kubesrv`

### Shell Access
- Added static busybox for debugging (403 commands available)
- Enables `kubectl exec` into pods
- Image size: 1.19MB (vs 59KB without shell)

## Security

### Critical Fixes
- **Path Traversal Protection**: Blocks paths containing `..`
- **Buffer Overflow Protection**: Enforced null termination on file reads
- **Error Handling**: Proper logging for file operation failures
- **Supply Chain Security**: SHA256 verification for busybox binary

## CI/CD

- Added fast CI workflow for PRs and commits
- Build/push workflow now only triggers on version tags
- Optimized with GitHub Actions cache

## Configuration

```yaml
env:
  - name: MESSAGE_FILE
    value: "/usr/share/kubesrv/greeting.txt"
volumeMounts:
  - name: config
    mountPath: /usr/share/kubesrv
    readOnly: true
volumes:
  - name: config
    configMap:
      name: my-config
```
